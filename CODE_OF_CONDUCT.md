# Code of conduct

We want Viper to be a welcoming, professional project.

**Expected:** be respectful and constructive; assume good faith; give and accept feedback graciously; keep discussion
on the technical merits; respect privacy.

**Not acceptable:** harassment, discrimination, personal attacks, doxxing, or sharing others' private information;
and, specific to this project, requests for help attacking systems the requester is not authorized to test.

Maintainers may edit, reject or remove contributions that violate this code and may restrict participation. To report
a concern, contact the repository owner through the private channels on their GitHub profile.

This code is adapted from the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/).
